# termoplastikuygulamarehberi

`www.termoplastikuygulamarehberi.info` için hazırlanan basit bir tanıtım ve rehber uygulaması.

## Özellikler
- Termoplastik üretimde yaygın problem/çözüm kartları
- Anahtar kelimeye göre arama
- Uygulama alanına göre filtreleme
- Seçilen kayıt için sağ tarafta canlı ön izleme paneli
- Tamamen statik (HTML/CSS/JS), hızlıca deploy edilebilir

## Lokal çalıştırma
```bash
python3 -m http.server 8000
```
Ardından tarayıcıdan `http://localhost:8000` adresine gidin.
